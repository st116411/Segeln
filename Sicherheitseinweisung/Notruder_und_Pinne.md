# Notruder
Auf den meisten Charteryachten gibt es kein Notruder deshalb kann man hier der Crew recht wenig zeigen. Falls es ein Notruder gibt kann diese am Heckspiegel eingehängt werden. Auf Langfahrt-Yachten wird alternativ oft eine Windsteueranlage (z. B. Hydrovane) so konstruiert, dass deren Ruderblatt im Ernstfall als Notruder fungieren kann.

- **Improvisation**: Fehlt ein fertiges Notruder, muss die Crew ein Ruder improvisieren – beispielsweise durch ein stabiles Brett (z. B. die Passarella/Gangway oder den Spinnakerbaum), das fest mit einer schweren Trosse, einem Fender oder einer Pütz (Eimer) als Widerstand im Wasser verbunden und über die Heckklampen angesteuert wird.

# Notpinne
Die Notpinne kommt zum Einsatz, wenn das Radsteuerungssystem ausfällt (z. B. durch einen Riss der Steuerseile oder Kette), das Ruderblatt selbst aber noch intakt ist.
• Funktion: Sie ist ein einfacher Hebel (meist aus Metall), der im Notfall direkt auf den aus dem Cockpitboden ragenden Ruderschaft (den oberen Teil der Ruderachse) gesteckt wird.
• Wirkung: Das Schiff wird damit von Radsteuerung auf direkte Pinnensteuerung umgestellt. Der Rudergänger steuert das Schiff nun mit Muskelkraft direkt über die Notpinne. Die Notpinne kann über die Winschen gelegt werden um es leichter steuern zu können bei schwerem Wetter.
• Besonderheit: Auf fast allen modernen Segelyachten mit Steuerrad gehört eine Notpinne zur gesetzlich vorgeschriebenen Sicherheitsausrüstung. Der Zugang zum Ruderschaft ist meist mit einer Schraubkappe im Cockpitboden abgedeckt.
